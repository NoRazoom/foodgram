Проект представляет собой сайт с рецептами, поддерживающий регистрацию и взаимодействия пользователей. Вы можете создавать, просматривать, удалять и изменять свои рецепты. Если у вас нет рецептов, можете выбрать подходящие вам, скачивать список продуктов рецептов, добавленных в корзину. Также рецепты можно добавлять в корзину, а на авторов понравившихся рецептов подписаться. Они могут подписаться в ответ, но только если вы авторизованы.

Запуск программы:
Находясь в папке infra, выполните команду docker-compose up. При выполнении этой команды контейнер frontend, описанный в docker-compose.yml, подготовит файлы, необходимые для работы фронтенд-приложения, а затем прекратит свою работу.

По адресу http://localhost изучите фронтенд веб-приложения, а по адресу http://localhost/api/docs/ — спецификацию API.

Для полноценной работы сисетемы, если планируете использовать github actions, необходимо добавить github secrets. Необходимо указать параметры DOCKER_PASSWORD, DOCKER_USERNAME, HOST, SSH_KEY, SSH_PASSPHRASE и USER. Он автоматизирует развертывание проекта на сервере: собирает докер-контейнеры, отправляет их на dockerhub, скачивает в указанную (в файле main.yml) директорию и запускает. Предусмотрено тестирование pep-8, установка зависимостей в контейнере бекенда ("username"/foodgram_baskend),

В рабочей директории создайте файл переменных окружения, который должен содержать в себе POSTGRES_USER, POSTGRES_PASSWORD, POSTGRES_DB,DB_NAME, DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, SECRET_KEY, DEBUG.

Если вы не планируете использование CD/CI, вручную собирите докер-образы из директорий infra, backend, frontend комаднами вида docker build "username"/foodgram_"image_name". Далее вам нужно запустить контейнеры командой docker compose up -d, находясь в директории с файлом docker-compose.yml (в папке infra). Перейдя в контейнер бекенда командой docker exec -it "username"/foodgram_backend bash. Выполните миграции, соберите и скопируйте статику в директорию для volume.
